## Ответы на вопросы

**1. Чем статическая типизация Dart отличается от Python? Какое практическое преимущество она даёт?**
В Python типы проверяются только во время выполнения программы. В Dart типы проверяются на этапе компиляции. Практическое преимущество: если ты ошибёшься с типом, Dart не даст даже запустить программу, а Python упадёт с ошибкой только в момент выполнения.

**2. Что означает `String?`? Чем отличается от `String`?**
`String` - это строгий тип, переменная с этим типом **не может** быть `null`. 
`String?` - это nullable-тип, переменная **может** содержать `null`. Компилятор заставляет тебя проверять такую переменную перед использованием, чтобы программа не упала.

**3. Зачем в Dart `final`, если в Python можно просто договориться не менять переменную?**
В Python «договорённость» - это просто слова, её легко нарушить случайно. В Dart `final` - это жёсткое правило на уровне компилятора. Если ты попытаешься изменить переменную после её первого присвоения, программа просто не скомпилируется. Это защищает от случайных ошибок.

**4. Чем именованный параметр `{required String name}` отличается от позиционного? Приведите пример вызова.**
Позиционный параметр передаётся по порядку, а именованный - по имени. 
Преимущество именованных в том, что при вызове функции сразу видно, что за значение ты передаёшь, и их порядок не важен.
